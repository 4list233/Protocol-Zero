# Docs index

This repo’s documentation is organized by topic:

- `docs/overview/` - high-level pointers and key files
- `docs/workflows/` - end-to-end operational workflows
- `docs/variants/` - variant system architecture and restructuring docs
- `docs/knack/` - Knack schema/seed/setup notes
- `docs/pricing/` - pricing model, setup, and promo code tracking
- `docs/scraper/` - scraper plans, requirements, and v2 docs
- `docs/media/` - hero images + image binding guides and SOPs
- `docs/shop/` - shop/frontend build and implementation notes
- `docs/security/` - audits and security notes
- `docs/ops/` - operational checklists and maintenance guides
- `docs/products/` - product folder system and related references
- `docs/integration/` - integration summaries and completion notes
- `docs/archive/` - historical docs that are no longer current
